# A.D.I. — releases

Signed installers and the update feed for **A.D.I. — Asset Delivery Interface**, by Dudkiewicz Corp sp. z o.o.

This repository holds releases only. The source code is private.

- Every installer is signed with **Dudkiewicz Corp sp. z o.o.**'s certificate through Microsoft Artifact Signing. Windows shows the company as the publisher.
- Installed copies of A.D.I. check this repository for updates and install them when the app is closed.
- A.D.I. requires signing in; an account has to be approved before the app opens.
